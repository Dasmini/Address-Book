# 📒 Address Book in C

A simple Address Book application developed in C.

## Features

- Create Contact
- Search Contact
- Edit Contact
- List Contacts
- Delete Contact
- Save contacts to file

## Technologies

- C
- Git
- VS Code
- WSL

## compile

```bash
gcc *.c
```

## Run

```bash
./a.out
```
